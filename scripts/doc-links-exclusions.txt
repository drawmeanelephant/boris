# Boris documentation link-guard exclusions
# (read by scripts/test-doc-links.sh, wired as `zig build test-doc-links`).
#
# Format: one entry per line; blank lines and '#' comments are ignored.
# Entry forms:
#   tree <glob>         skip whole subtrees whose "links" are fixture or test
#                       placeholders, not navigable documentation. <glob> is
#                       matched against the repo-relative markdown path.
#   link <src>|<target> allow one archival-by-intent link: exact match on
#                       "source file|target".
#
# Every entry must be preceded by a comment saying why it exists, so adding
# an exclusion is a deliberate, reviewed act rather than a silent widening
# of the guard's blind spot.
