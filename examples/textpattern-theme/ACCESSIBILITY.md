# Accessibility notes

The Textpattern port keeps the strong editorial identity without making the
page depend on color, hover, a pointer, or a runtime script.

- Each layout has a skip link, a named `main`, a banner/header, and a
  contentinfo footer.
- Navigation, breadcrumbs, and the table of contents remain ordinary links
  generated by Boris. The navigation disclosure uses native `<details>` and
  `<summary>` so it remains keyboard-operable without JavaScript.
- Focus rings use a solid high-contrast crimson/gold treatment with an offset
  so links remain visible on both paper and dark masthead surfaces.
- The mark is decorative where adjacent text already names the site; the
  page-local press-cycle diagram has descriptive alternative text and SVG
  metadata.
- Tables scroll horizontally when needed instead of shrinking into an
  unreadable grid. Code blocks are scrollable and preserve their language
  class from Oliver.
- The desktop two/three-column compositions collapse into a single reading
  order at 860px. Navigation, metadata, children, and the TOC are never
  hidden; they become normal stacked regions.
- `prefers-color-scheme: dark` changes the paper, ink, rule, and code tokens,
  while `prefers-reduced-motion: reduce` disables smooth scrolling and
  transitions.
- Callouts retain a text label (`Note`, `Tip`, `Info`, `Warning`, or `Danger`)
  in addition to their border color. Native disclosure summaries retain a
  visible marker and focus state.

This is a theme-level accessibility pass. It does not claim to replace a
manual screen-reader, keyboard, zoom, or contrast review of the rendered
site.
