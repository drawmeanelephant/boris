    Getting Started with Boris

    Boris is a graph-native publication compiler. Markdown in. A validated Trunk/Satellite graph. Then you choose a target. HTML dist/ is the default — not the product.

    The shortest useful path is: build Boris, preflight the sample content, build the site, open the HTML. Hosted targets come after that.

    Info

    The default HTML build also publishes a rendered-search artifact and target-local publication evidence. You do not need to run a second search index command for a normal Boris build.

    Prefer closed frontmatter keys (id, title, parent, status, tags, relations, published_at, summary) and double-quoted Aside attributes. Fragment files under content/includes/ are not site pages — only the include directive pulls them into a page body.

    1. Build Boris

    Building Boris itself requires:

    • Zig 0.16+ — the compiler language Boris is written in. Markdown rendering uses the Oliver library, pinned in build.zig.zon and fetched by Zig at build time — no CMake or other host tools are required.
    git clone https://github.com/drawmeanelephant/boris.git
cd boris
zig build

    The binary is written to ./zig-out/bin/boris.

    2. Inspect the sample content

    Pages are ordinary Markdown files under content/. The path without its extension is normally the page's entity id: content/guides/overview.md becomes guides/overview. Start with Building Pages if you want to add a page, or the Markdown showcase if you want to see what Oliver will actually render.

    3. Preflight without publishing

    ./zig-out/bin/boris validate --quiet

    validate runs Boris's authoritative HTML source and configuration checks, including graph resolution, component parsing, layout loading, and bounded render preparation. It creates no HTML, cache, search, or publication-evidence files.

    Tip

    validate is not check. check is graph-health policy after the graph is already valid. Use validate to ask “would this compile?” Use check to ask “is this graph healthy?”

    4. Publish the static site

    ./zig-out/bin/boris build --quiet

    The default target is dist/. Open dist/index.html directly for reading, or serve the dist/ directory with any static file server when you want the browser search UI to fetch its same-origin index.

    A first-time author publishes local HTML. Hosted targets come after you can open dist/index.html and point at a broken parent with a straight face.

    5. Then choose a hosted target

    Local dist/ is the default. It is not the only exit.

    What you should not do on day one

    Do not start with browser OAuth against bsky.social. Do not type an app password on argv. Do not edit files under dist/. Do not run the standalone search-index tool after a normal Boris build. Do not invent a boris nostr command because you read a roadmap issue.
