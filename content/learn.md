# Learn

This is the working tour: how to write pages, connect them, and choose the
right output. You can read it in order or jump directly to the thing you are
trying to make.

| Topic | Start with |
|---|---|
| Content structure | [[guides/overview|Content Model Overview]] |
| Markdown and callouts | [[guides/apex-markdown|Apex Markdown Showcase]] and [[guides/asides|Using Asides]] |
| Parent and child pages | [[guides/trunk-satellite|Trunk and Satellite Pages]] |
| Commands and outputs | [[guides/cli-and-modes|CLI and Run Modes]] |
| Retrieval exports | [[guides/rag-export|RAG Export Packaging]] |

The useful order is human-first: decide what a reader needs to know, make the
relationships explicit, then let Boris render the structure.
