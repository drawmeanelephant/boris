# Accessibility notes

The gallery theme is built around images, but it does not depend on them,
on color, on hover, on a pointer, or on any script.

- Each layout has a skip link to `#main-content`. That is a focusable
  (`tabindex="-1"`) `<main>`, alongside a banner header and a contentinfo
  footer.
- Breadcrumb, parent link, children grid, relations, backlinks, and the
  site index are ordinary links generated by Boris. The site index uses
  native `<details>`/`<summary>`, so it works from the keyboard without
  JavaScript.
- The child grid is a list of real links. Each tile's "No. 01" plate number
  is generated by CSS and is decorative. The link text is the page title.
  Hover lifts the tile by 2px. Keyboard focus gets its own ring.
- `:focus-visible` draws a 3px blue outline with an offset (light blue in
  dark mode), and it stays visible on the wall, mat, and image surfaces.
- Alt text is the author's job and the specimen models it: alt describes the
  picture and `<figcaption>` labels it. The theme never hides `alt`, and it
  never puts text over an image.
- Images are capped at 85% of viewport height (60% inside a
  `gallery-grid`), so a portrait plate and its caption fit on one screen.
  Images are never cropped with `object-fit`.
- Captions use a left rule and their own type style, so they read as labels
  without relying on color.
- Aside callouts keep their text label (`Note`, `Tip`, `Info`, `Warning`,
  `Danger`) in addition to the colored border. Details summaries keep the
  native disclosure marker.
- Tables scroll horizontally instead of shrinking. Code blocks scroll and
  keep Oliver's language class.
- Below 40rem everything stacks into a single reading order. Figures run
  edge to edge, definition lists become one column, and grid tiles drop
  their fixed aspect ratio. Nothing is hidden at narrow widths.
- `prefers-color-scheme: dark` swaps the palette tokens and leaves images
  alone. `prefers-reduced-motion: reduce` turns off smooth scrolling, tile
  transitions, and the hover lift.
- The print stylesheet removes the skip link, breadcrumb, site index, child
  grid, and relations, keeps figures and captions together on a page, and
  prints black on white.
- Empty chrome regions are hidden with `display: none`, so they do not show
  up as empty landmarks.

This is a theme-level accessibility pass. It does not replace a manual
review of the rendered site with a screen reader, keyboard, zoom, and a
contrast checker.
