the no-JavaScript path.

- Layouts: `main.html`
- Specimen: [`examples/studies-site/`](../../examples/studies-site/)

```bash
./zig-out/bin/boris \
  --input examples/studies-site/content \
  --theme themes/minimal \
  --html-dir test-output/minimal \
  --quiet
```
