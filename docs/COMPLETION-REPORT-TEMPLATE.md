# Completion Report Template

The canonical completion report format is in the [PR template](../.github/PULL_REQUEST_TEMPLATE.md) and the [issue template](../.github/ISSUE_TEMPLATE/completion-report.md). The issue-close rules for the **Linked Issues** field live in the header of [`scripts/check-pr-issue-close.sh`](../scripts/check-pr-issue-close.sh). Check a PR body locally with `scripts/check-pr-issue-close.sh --body-file <path>`.
