### Added

- The [editor](/content/guides/editor.md) Ctrl+K command palette now also
  runs editor commands: Save file, Validate project, Build diagnostics,
  Build HTML, Check graph, Run impact, Rebuild preview, and Focus source
  pane. Commands and preview rebuilds still route through the
  unsaved-changes resolution dialog when the buffer is dirty
  ([#462](https://github.com/drawmeanelephant/boris/issues/462)).
