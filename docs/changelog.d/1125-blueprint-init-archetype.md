### Added

- New `blueprint` documentation theme and `boris init --type blueprint`
  starter: a docs shell in the Bootstrap 6 token grammar (Boris-owned
  names, no vendored code) with a search header, a `{{nav}}` sidebar that
  becomes a CSS-only mobile drawer, a collapsible `{{toc}}` rail, and
  `main`, `home`, and `section` layouts. The starter is a ten-page site for
  a fictional task runner, with Getting started, Guides, and Reference
  sections and a draft guide. Links: [the init contract](/docs/contracts/cli.md#init-deterministic-starter-scaffold-with-self-verification),
  [the theme catalog](/themes/README.md).
