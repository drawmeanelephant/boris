### Docs

- The CLI contract now specifies the version query for tooling: `boris
  --version` / `-V` print the compiler id (`pipeline.compiler_id`, e.g.
  `boris/0.8.1`) as a single stdout line and exit 0, with pinning and
  artifact-provenance recipes. See
  [`cli.md`](/docs/contracts/cli.md) § Version query.
