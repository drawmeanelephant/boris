### Added

- The [editor](/content/guides/editor.md) now has a Ctrl+K command palette
  for file actions: type to filter, arrow keys to navigate, Enter to run.
  Create, Rename, and Delete reuse the existing dialogs, and Open file
  entries route through the unsaved-changes resolution dialog when the
  buffer is dirty
  ([#462](https://github.com/drawmeanelephant/boris/issues/462)).
